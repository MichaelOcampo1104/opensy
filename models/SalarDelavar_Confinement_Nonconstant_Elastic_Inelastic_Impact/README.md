# SalarDelavar_Confinement_Nonconstant_Elastic_Inelastic_Impact

**Purpose:** Comparison of the elastic and the inelastic behaviour of the 2D reinforced-concrete frame of `CONFINEMENT_NONCONSTANT_ELASTIC_OR_INELASTIC_FRAME` under the source's harmonic horizontal load at nodes 3 and 4 (titled "harmonic impact loading" in the source): a monotonic pushover to 675 mm (bilinear fit, over-strength factor, ductility, R and the damage index) and a 100 s time history with the source's Rayleigh damping. Second sub-model of the source folder `CONCRETE_FRAME_EXAMPLES/CONFINEMENT_ENHANCEMENT_RATIO`, which holds seven sub-models.

**Building System:** The same frame as the first sub-model: a single-storey, single-bay portal frame with both bases fixed. The columns are 3 m high and 500 x 500 mm, with 50 mm cover and six 25 mm bars (three on each face in the plane of the frame). The beam spans 7 m between the column axes and is 500 mm wide and 300 mm deep, with 50 mm cover and eight 18 mm bars (three top, two middle, three bottom). The confinement enhancement ratio is 1.25 for elements 1, 3, 4 and 6, 1.10 for elements 2 and 5, 1.15 for elements 7 and 9 and 1.05 for element 8, as in the source.

**Model Description:** 2D model with three DOFs per node (ndm = 2, ndf = 3) and ten nodes. Nine corotational beam-column elements. The inelastic run uses `nonlinearBeamColumn` with 10 integration points; the elastic run uses `elasticBeamColumn` on the same fibre sections (Note 3). Each section has its own materials, as in the source: Concrete01 for the core (strength 25 MPa times the ratio) and for the cover (25 MPa), and Hysteretic reinforcement (f_y = 4000 MPa, E_s = 2 x 10^5 MPa). The fibres form 40 x 5 patches. Analyses, each run for both element kinds:
1. Pushover: horizontal displacement control of node 4 (DOF 1) from 0 to 675 mm in 0.05 mm steps (13,500 steps) with SmartAnalyze (NormDispIncr, tolerance 1 x 10^-6, 5000 iterations, algorithm ladder 10, 41, 40, 20, 50, 60). The reference load is 1 N horizontal and -1 N vertical at nodes 3 and 4, and the load factor is the output. This is the same model and load as the first sub-model, and its results agree with that sub-model's (Validation). Recorded at each step: load factor, node-3 displacements and rotation, base reactions (sum over both bases) and the stiffness ratios KS, KA and KI.
2. Harmonic time history: the source's values F_k = 1 MN sin(0.65 omega_n t_k), with omega_n = 5.0715 rad/s, are applied as a Path series at the step DT = 0.01 s. The force is a horizontal load of 1.0 times the series at nodes 3 and 4 (source IMA = 'X'). The run lasts 100 s (10,000 steps) with Newmark (0.5, 0.25) and SmartAnalyze (ladder 10, 41, 40, 20, 50). Modal Rayleigh damping from the first two modes (5 % and 3 %) through the source's helper. Recorded at each step: displacements and velocity and acceleration of node 3, base reactions, the stiffness ratios and the shortest and longest of the first four periods. The values last 49.99 s and the force is zero after that (Notes 4 and 6).

**Validation:** `output/validation.txt`, from the final run of this folder:
- **Element assembly.** The force-based element with gross sections reproduces the textbook frame element to 1.7 x 10^-15.
- **Section properties (gross, initial tangents).** Column EA = 5.851 x 10^9 N and EI = 1.427 x 10^14 N.mm^2; beam EA = 3.576 x 10^9 N and EI = 2.996 x 10^13 N.mm^2.
- **First pushover step, elastic run.** OpenSees 1068.832 and numpy 1068.849 (relative difference 1.6 x 10^-5).
- **First pushover step, inelastic run.** OpenSees 299.8451 and numpy 299.8672 (7.4 x 10^-5), with the section states of the first step and 10 Lobatto points. The node-3 displacement is 0.04502298 mm (OpenSees) and 0.04502249 mm (numpy).
- **Equilibrium** over all 13,500 steps. Elastic: 9.1 x 10^-15 (horizontal) and 8.8 x 10^-14 (vertical). Inelastic: 3.8 x 10^-12 and 1.9 x 10^-11.
- **Periods and Rayleigh coefficients.** The four lowest periods of the frame with the lumped mass (LESSON 69) are 7.584309, 2.440709, 1.832704 and 1.030376 s, which match OpenSees to six digits. The numpy coefficients alpha_M = 7.457112 x 10^-2 1/s and beta_K = 1.205471 x 10^-2 s match the OpenSees values, and they give modal ratios of 5.0000 % and 3.0000 % for modes 1 and 2.
- **The harmonic load as applied** (Note 4; LESSON 74). The applied frequency is 0.32971 rad/s (period 19.06 s), against the intended 3.29648 rad/s (period 1.906 s). The applied series lasts 49.99 s.
- **Elastic time history against a linear Newmark replica with the same load** (LESSON 75). Node-3 displacement: 8.0 x 10^-7 over the first 83 steps (t <= 0.83 s), while |u| <= 1 mm; 3.1 x 10^-4 over 189 steps (t <= 1.89 s), while |u| <= 10 mm; 3.3 x 10^-3 over the whole 100 s record. The last figure comes from the corotational transformation of the run (Note 1; LESSON 72). With a linear transformation the same model agrees with the replica to 1.5 x 10^-11 over all 10,000 steps (Note 17).
- **Base shear of the time history:** not validated (Note 16).
- **Not validated:** the inelastic time history, beyond its first periods. The bilinear fit, the over-strength factor, the ductility and R are the source's formulas, ported, and are reported rather than checked against an independent solution.

**Notes:**
1. **Corotational transformation.** Both runs use the source's corotational transformation, so the elastic run is linear in its materials only. Its geometric nonlinearity departs from a linear replica once the displacement exceeds about 1 mm (Validation). The linear-geometry check of Note 17 is the reference for that departure.
2. **Cracked from the first step.** Concrete01 has no tensile strength, so the inelastic frame is cracked from the first pushover step: its first load factor is 299.8, against 1068.8 for the gross elastic frame (ratio 0.28). The gross section is not a reference for the inelastic run (LESSON 65 for the composite section model).
3. **Elastic branch.** The source's ELASTIC branch calls `elasticBeamColumn` with the fibre section tag. OpenSeesPy 3.8 accepts this and gives the element the linear stiffness of that section (gross, initial tangents). A scratch probe with the source's concrete and steel stayed linear to 0.03 % at a tip displacement of 63 mm, whereas the nonlinear element was 3.5 times as flexible at 10^4 N. The elastic first step agrees with the gross numpy frame to 1.6 x 10^-5.
4. **Harmonic load: timing and the stated frequency.** The source computes its values on `load_time = linspace(0, 0.1 x impact_time, impact_time/dt)`, a span of 5 s with a spacing of 0.0010002 s, and then applies them as a Path series with `-dt 0.01`. Each value is therefore applied at 0.01 s, not at 0.0010002 s, and the applied load runs at 0.1 times the source's stated frequency: 0.32971 rad/s (period 19.06 s), against the intended 0.65 omega_n = 3.29648 rad/s (period 1.906 s). Its first zero crossing comes at 9.53 s instead of 0.953 s, and the values last 49.99 s. The conversion keeps the source's values, so it reproduces the source, and the response below is that of the applied load (LESSON 74). The source's omega_n = 5.0715 rad/s (period 1.2389 s) is a constant typed into the script, not computed. This frame's first two periods are 7.584 s and 2.441 s (Note 5), so the constant matches neither (LESSON 77). The figure `harmonic_load.png` shows both time axes.
5. **Masses.** The source labels its nodal mass `MASS = 12000` as [kg] and takes its element masses from the factors `Bc*Hc*0.000025 = 6.25` and `Bb*Hb*0.000025 = 3.75`. OpenSees uses the N-mm-s system here, so every value is read as N.s^2/mm (per unit length: N.s^2/mm^2). As written, the total mass is 87,750 N.s^2/mm (87,750 t). The periods are then 7.58, 2.44, 1.83 and 1.03 s. Read as kg, every mass is 1000 times smaller and the periods are 0.0316 times these: 0.240, 0.077, 0.058 and 0.033 s, so the shortest period spans only 3.3 steps of dt = 0.01 s. As a density, the element mass of 6.25 N.s^2/mm^2 is about 10^4 times the mass of a 500 x 500 mm concrete column at 2500 kg/m^3. The values are kept as written, and the choice is left to the author (LESSON 71).
6. **The Path series is zero after its last value.** The source's values end at 49.99 s with -0.699 MN, and the run lasts 100 s. OpenSees applies no force after that point: its displacements after 50 s agree with a replica that applies zero force (2.7 x 10^-3 of the largest displacement after 50 s), and a replica that holds the last value differs by 1.59 times that maximum (LESSON 76).
7. **Rayleigh damping.** The source's helper computes alpha_M and beta_K from the first two modes, with 5 % for mode 1 and 3 % for mode 2 (the call uses `DR` and `0.6*DR`). It passes beta_K as the fourth argument of `ops.rayleigh`, which is the committed-stiffness coefficient, although its comments describe a current-stiffness coefficient. Kept as written. The difference matters only for the inelastic run, where the stiffness term acts on the last converged stiffness.
8. **Excitation force.** The harmonic load is a nodal force, so OpenSees applies no element-mass term to it. The replica applies the series to nodes 3 and 4 only, with the lumped mass and the nodal masses in the inertia and damping terms (LESSON 75). This differs from the first sub-model, whose ground motion is applied through the element masses (LESSON 70).
9. **Source text that does not apply here.** The source's header refers to El Centro records scaled by 0.01 g, but this run has no records. The source defines `GMfact` = 9810 mm/s^2 and uses it only in a `WEIGHT` value that its pushover does not use. The `SEI` and `SSF` branches of the first sub-model are not in this source.
10. **Logarithmic decrement.** The source's `DAMPING_RATIO` function returns 0 when any local maximum of the displacement is not positive. The elastic and inelastic time histories return 4.714 % and 10.477 %. The record is forced, so the value is not a modal damping ratio (LESSON 62). The modal ratios of the coefficients are in Validation.
11. **Node 3 and node 4.** The pushover controls node 4 (DOF 1) to 675 mm, and the source records node 3. At the end of the inelastic pushover, the node-3 displacement is 683.6 mm, which is larger than the control. The bilinear fit, the ductility and R use the node-3 displacement, as the source does.
12. **Bilinear fit and damage index.** The equal-area fit of the inelastic pushover (slope node 10, as the source) gives Omega_0 = 1.1615 and mu = 5.7515, so R = 6.6802. The damage index is 0.8677 in X, from the peak node-3 displacement of the inelastic time history (608.9 mm, at 20.64 s). The axial fit gives Omega_0 = 0.9264, a value below 1 that the source's formula returns as written, and a damage index of 0.6380 in Y.
13. **Solver and period helper.** Both pushovers completed all 13,500 steps to the 675 mm control, and both time histories completed all 10,000 steps with SmartAnalyze. In the inelastic history, 4 of the 10,000 steps (at 15.67, 15.68, 16.81 and 16.90 s) have a negative eigenvalue of the tangent stiffness, so the source's period helper (minimum and maximum of four eigenvalues) returns NaN there. The period ranges in `dynamic_results.txt` use the finite values, 1.39 s to 102.53 s for the inelastic history, and state the NaN count.
14. **Output files.** The source's Excel export is written as CSV: `dynamic_elastic.csv` and `dynamic_inelastic.csv` (10,000 steps, with a TIME column) and `pushover_elastic.csv` and `pushover_inelastic.csv` (13,500 steps each).
15. **Not converted.** The Y record and the `SEI = 'Y'` and `'XY'` branches, and the impact direction `IMA = 'Y'` and `'XY'` of the source. The fallback ladder of `ANALYSIS_FUNCTION.py` is replaced by SmartAnalyze. The printed text is replaced by the result files, and the matplotlib windows by PNG files. `PLOT_2D.py` (not run) and `SALAR_MATH.py` (not imported by the source's main) are kept as copies only. The source's stress-strain recorders are not in this source.
16. **Base shear of the time history.** The replica does not reproduce the base shear: the OpenSees reaction includes the element inertia and damping forces at the bases, and their convention was not isolated here. The base shear is therefore not validated.
17. **Scratch checks (not in this folder).** These were run from a scratch folder and are cited for transparency: the elastic harmonic run with a linear transformation agrees with the replica to 1.5 x 10^-11 over all 10,000 steps; the replica with the last value held differs from OpenSees by 1.59 times the largest displacement after 50 s (LESSON 76); and a cantilever and a single mass on a spring were checked in the first sub-model (LESSONS 69 and 70).
18. **Run time.** Measured on this machine while the ductility sub-model's run shared the processor: the elastic pushover took 20 s and the inelastic pushover 8 min 20 s (13,500 steps each). The elastic time history took 19 s and the inelastic one 4 min 6 s (10,000 steps each). The whole script took about 13 minutes. The console must use UTF-8: the progress bar prints a rocket emoji, which stops a cp1252 console with redirected output (LESSON 35).

**Outputs** (in `output/`, git-ignored): `pushover_elastic.csv` and `pushover_inelastic.csv` (13,500 steps, with the source's column names), `dynamic_elastic.csv` and `dynamic_inelastic.csv` (10,000 steps, with TIME), `pushover_results.txt`, `dynamic_results.txt`, `validation.txt`, `model_info.json` (the OpenSees model of the last analysis), the figures `harmonic_load.png`, `pushover_curve.png` and `dynamic_response.png`, the views `vis_01_nodes.html` to `vis_04_pre_analysis.html`, `vis_05_deformed_inelastic_pushover.html`, `vis_08_pushover.html` and `vis_09_dynamic.html`, and the ODBs `RespStepData-*.odb` with their `ModelData-*.zarr` folders for the four analyses.
