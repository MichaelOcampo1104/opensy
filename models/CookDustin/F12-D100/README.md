# CookDustin F12-D100 — 2D 4-Bay × 12-Story RC SMF Pushover

2D RC special moment frame with concentrated plasticity hinges
(IMKPeakOriented) and a leaning column. Gravity then displacement-controlled
pushover to 10 % roof drift. Based on the FEMA P695 "m112v5" archetype from the
NHERI SimCenter pipeline (Cook Dustin).

## Source

Reference files in `F12-D100_ref/`:
- `model.tcl` — auto-generated by the SimCenter *StandardizeModel* workflow
- `node.csv`, `element.csv`, `element_table.csv`, `story.csv`, `hinge.csv`,
  `component_inventory.csv`, `model.csv`, `joint.csv` — pipeline input data

Tcl is model-only (no analysis); analysis section (gravity + pushover) added in
`model.py`. Units converted from lb-in-psi to N-mm-MPa.

## Usage

```bash
conda activate opensy
python models/CookDustin/F12-D100/model.py
```

## Approach

`model.py` parses `model.tcl` directly for all materials, elements, nodes, and
boundary conditions — guaranteeing exact match with the reference. CSVs are
only used for story gravity load distribution (story D+0.25L from `story.csv`
proportioned by nodal masses from `node.csv`). IMKPeakOriented K₀ and Mₚ
values are converted lb·in → N·mm; Elastic material A, E, I₂ and psi → MPa.

## Output

HTML visualisations written to `output/`:

- `vis_02_model.html` — undeformed geometry with numbering
- `vis_03_loads.html` — load vectors
- `vis_04_pre_analysis.html` — final geometry check
- `vis_05_deformed_UX.html` — deformed shape (deformation slider)
